# TERMINAL QUIZ GAME

## About

A light, interactive terminal quiz game written Bash script. The game loads multiple-choice questions from a plain text file, presents them in random order, tracks the player's score and saves scores to a local file.

## Game Features

- Loads questions from a simple text file questions.txt
- Presents questions and answer choices in the terminal.
- Tracks score, correct/incorrect counts, and current streak.
- Saves and displays scores in highscores.txt

## How to Play

Open your terminal.

Run the quiz script. ./quiz.sh

Enter the correct answer letter (A, B, C, or D).

Your score updates automatically as you play.

You can update the questions file to add your own quizzes.

## Files

- 'quiz.sh' — Main Bash script to run the game.

- 'questions.txt' — Questions file. Each line contains one question in the format:

Question text |A) option1 |B) option2 |C) option3 |D) option4 |Answer: X

- highscores.txt — Generated by the script to store scores.

## Typical flow

1. The game greets the player and asks for a name (optional).
2. Questions appear one at a time with choices A–D.
3. Enter your answer (A, B, C, or D). Input is case-insensitive.
4. The game shows whether the answer was correct and updates score/streak.
5. At the end, the final score and statistics are shown, and the score may is saved to highscores.txt

## Question File Format (Detailed)

- Each question must be on a single line.
- Fields are separated by the pipe character (|).
- The final field must be `Answer: X` where `X` is `A`, `B`, `C`, or `D`

## Quick Start

1. Run ./quiz.sh and play.
